TOKENTOP ANIME 3D — VS CODE YO'RIQNOMASI

1) ZIP faylni yuklab oling.
2) ZIP ustiga o'ng tugma bosing -> Extract All... -> Extract.
3) Visual Studio Code'ni oching.
4) File -> Open Folder... ni tanlang.
5) Chiqarilgan TokenTop_3D papkasini tanlang.
6) index.html, style.css va app.js fayllari shu yerda.
7) Oddiy tekshirish uchun index.html faylini brauzerda oching.
   VS Code'da Live Server o'rnatilgan bo'lsa, index.html ustiga o'ng tugma -> Open with Live Server.
8) O'zgartirish kiritgach, brauzerda Ctrl+R bosing.

NIMALAR QO'SHILDI?
- Anime uslubidagi CSS qahramon ko'rinishi.
- Kiyim kartalariga 3D soyalar va aylanish effektlari.
- Kiyimlarda "Kiyib ko'rish" tugmasi.
- Alohida Promokodlar bo'limi va 50 ta TT-ANIME-01 ... TT-ANIME-50 kodlari.
- Kodlar 50, 75, 100, 125 yoki 150 token mukofot beradi.

MUHIM:
Bu demo versiya. Promokodlar brauzerning localStorage xotirasida saqlanadi. Foydalanuvchi brauzer ma'lumotlarini tozalasa yoki boshqa qurilmadan kirsa, kodni yana ishlatishi mumkin. Haqiqiy umumiy sayt uchun server va ma'lumotlar bazasi kerak.
Shuningdek, kiyimlar CSS/emoji ko'rinishidagi 3D effektli dizayn; bu to'liq 3D model fayllari emas.
